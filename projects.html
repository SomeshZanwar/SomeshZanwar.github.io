MetricTrust Control Plane
  • Built a governance control plane that intercepts AI analytics agent actions before execution — evaluating real dbt test evidence through deterministic YAML policies to decide whether to allow, escalate for human approval, or block.
  • Designed a short-lived RS256-signed execution permit system using PyJWT — permits expire after use and actively reject replay attacks and tampered tokens.
  • Implemented an automatic rollback layer that monitors post-execution guardrails and reverses agent actions when data quality checks fail after the fact.
  • Validated with 21 automated tests and 7 dbt data tests; deployed on Render with an end-to-end live demo covering the complete governance decision cycle.
Outcome Not just a policy engine — an execution control system that issues signed, expiring permits, escalates ambiguous cases to humans, rolls back bad actions, and leaves a verifiable audit trail.
