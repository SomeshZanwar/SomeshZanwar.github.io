Why It Matters

The
Direction

The core idea
AI agents should not only ask "Am I allowed to use this data?" They should also ask "Is this data reliable enough to use right now?" My AGT contributions explore this exact gap — building governance patterns where authorization and data trust are evaluated together, not separately.
The bridge built
The dbt-backed DataQualityEvidence adapter (PR #2278) is the clearest example: dbt test results — which already exist in analytics pipelines — become policy-readable evidence that governance and agent decision flows can consume. Analytics engineering meets AI governance at the artifact level.
